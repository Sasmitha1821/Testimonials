Task 5 – Testimonials Section

A responsive and interactive testimonials section built using **HTML, CSS, and JavaScript** as part of my frontend development task at **SpireX Foundation**.

✨ Features

* Responsive design
* Interactive testimonial slider
* Previous/Next navigation
* Dot navigation
* Auto-slide with pause on hover
* Star ratings
* Smooth animations

 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Fonts

🎨 Design

A unique **cream, terracotta, mustard, and sage** color theme designed for a modern and professional look.

📱 Responsive

Optimized for **desktop, tablet, and mobile** devices.
